# 贝壳应用图标与电视背景设计方案

这是本次已安装版本的视觉留档，可跨电视品牌复用；设备兼容、自启动和入口目标仍按主流程分别验证。保留方案是为了继续修改或重建时不丢样式，不表示以后任务均使用贝壳品牌。

## 原素材与成品

- [应用图标](../assets/beike-design/app_icon.png)：96×96 PNG，白色圆角底与彩色贝壳图形；本次首页应用和签约中心应用使用同一份文件。
- [电视应用横幅](../assets/beike-design/app_banner.png)：320×180 PNG，本次两个应用的横幅一致。
- [品牌横向Logo](../assets/beike-design/beike_logo.png)：270×96 PNG，保留透明背景。
- [品牌图形](../assets/beike-design/beike_mark.png)：114×114 PNG，用作背景低透明度装饰。
- [电视实机预览](../assets/beike-design/homepage-device-preview.png)：保留当时首页的整体效果和地点文案，未来地点与入口以新确认单为准。
- [绘制参考](../assets/beike-design/HomeCanvas-reference.java.txt)：从本次原生首页提取的视觉片段，已移除应用启动逻辑和设备包名、替换固定地点；用于重建样式，不是可直接安装的项目。

品牌素材在本次制作时来自贝壳官网 https://bj.ke.com/ 的页面资源，并由本地应用使用；这是历史来源记录，不代表未来官网仍使用同一文件。当前留存内容直接见上面的文件。不要用生成图重画品牌原标；需要更高清版本时获取官方或用户提供的原素材，不将96像素图标简单放大当作高清原稿。

## 背景和布局

以下均是本次设计参数，不是贝壳官方品牌规范。布局坐标采用1920×1080横屏参考画布，实际按电视尺寸适配；实机检查边距、裁切和文字，不能凭统一拉伸承诺所有比例适用。

| 元素 | 本次方案 |
| --- | --- |
| 基础背景 | 左上到右下渐变，#081B39 → #102A49 |
| 左上蓝色光晕 | 中心(250,100)，半径1200，#4573FF，透明度112/255 |
| 右上青绿光晕 | 中心(1720,240)，半径850，#48CCB6，透明度80/255 |
| 右下红紫光晕 | 中心(1630,1080)，半径900，#6F284F，透明度64/255 |
| 品牌图形水印 | 区域(1190,170)至(1900,880)，透明度17/255 |
| 左上Logo | 区域(100,78)至(336,162)；下方简短品牌文案 |
| 右上时间 | 右对齐至x=1820；时分字号66，日期字号23 |
| 中上标题 | x=100，基线y=325，字号52；副标题字号25 |
| 左主卡片 | (100,438)至(920,844)，签约中心入口 |
| 右主卡片 | (1000,438)至(1820,844)，投屏入口 |
| 底部工具区 | 分隔线y=938；左侧Wi-Fi与网络状态，右侧电视设置 |

光晕由中心颜色渐变到透明，背景保持低对比，不影响白色文字阅读。水印不覆盖主标题、主入口文字，不将业务信息直接烘焙进背景图片。

## 卡片、入口图标和遥控焦点

- 未选中卡片渐变#183C59 → #14324E；圆角32；标题白色43，说明#BFD1E6、24。
- 选中卡片向外扩9像素；背景#214D85 → #183B6A，外描边渐变#5A9DFF → #49C6C3，外扩3像素。
- 签约中心入口使用蓝底#328AF3的白色文件签字线图；投屏入口使用青绿底#35A99A的白色屏幕/无线线图。图形绘制见参考片段，不把这两种业务图标误当品牌Logo。
- 入口图标容器104×104、圆角29；线条4像素。选中状态显示“确认打开”，未选中显示“选择打开”。
- 底部按钮选中底色#2674C6；网络状态采用绿/粉提示并同时显示文字。原版本“已连接”依据Android网络能力判断，不等于已证明业务服务器可访问，后续功能需要区分这两件事。
- 方向键按上下两排移动，确认键打开；焦点要明显，避免只靠很小的颜色差异。

## 后续复用

同一首页继续修改时默认保留这套图标、深蓝渐变背景、彩色光晕、低透明度品牌水印及焦点样式；按确认单替换地点、入口和链接。其他品牌任务先确认是否沿用此风格，并替换相应品牌素材。

本次背景由Android Canvas实时绘制，没有单独的原始背景位图；实机预览、精确参数及绘制片段共同留档。若以后需要独立壁纸，可据此导出，另行检查最终尺寸与显示效果。

Canvas实现需保留颜色的alpha：普通填色设置半透明ARGB后不要再无条件setAlpha(255)；着色器、位图与透明度在每段绘制结束后正确恢复。此前该错误会把半透明底色画成不透明色块。
